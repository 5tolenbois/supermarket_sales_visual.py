# 超市销售数据可视化（Matplotlib）
> 数据科学与大数据技术｜Matplotlib多类型图表实战项目
对超市销售数据集进行多维度可视化分析，掌握Matplotlib各类图表绘制。

## 数据集介绍
- Date：销售日期
- Branch：分店A/B/C
- Product line：商品产品线
- Payment：支付方式
- Quantity：购买数量
- Unit price：商品单价
- Total：销售总额
- gross income：毛收入
- Rating：顾客评分

## 技术栈
Python Pandas、Matplotlib、Numpy
图表类型：折线图、饼图、柱状图、条形图、直方图、散点图、气泡图、热力图、雷达图、箱线图

4.1 超市数据集介绍
